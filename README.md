# Speech-Spectral-Analysis-using-DFT-and-Windowing-Techniques
MATLAB project for speech spectral analysis using DFT, FFT, STFT, windowing, and PSD. Includes preprocessing, envelope &amp; energy analysis, spectrograms, and comparison of Rectangular, Hamming, Hann, and Blackman windows. Shows speech behavior in time-frequency domain and effects of spectral leakage.
